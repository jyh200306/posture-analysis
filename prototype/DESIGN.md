# 디자인 시스템 — 자세 분석 프로토타입

> 원칙: **모노크롬 에디토리얼.** 검정과 하양, 타이포그래피와 여백만으로 위계를 만든다.
> 흔한 "AI 생성물" 룩(보라 그라데이션, 둥근 카드 + 그림자, 이모지 남발)을 의도적으로 배제한다.

---

## 1. 원칙

1. **색이 아니라 구조로 말한다.** 상태(양호/주의/불균형)는 색 대신 채움·선 스타일·텍스트 라벨로 구분한다.
2. **그림자 금지, 헤어라인 사용.** 깊이 표현은 1px 경계선(`--line`)과 여백으로만 한다.
3. **숫자가 주인공.** 점수는 큰 타블러 숫자(tabular-nums)로, 설명은 작게.
4. **사진은 흑백 처리.** 업로드된 사진은 grayscale 필터를 적용해 전체 톤을 통일하고, 골격 오버레이(흰 선)의 가독성을 높인다.
5. **모션은 짧고 기능적으로.** 150–200ms, opacity/transform만. 바운스·스프링 금지.
6. **이모지·장식 아이콘 금지.** 라벨은 텍스트로. 영문 보조 라벨(소문자/레터스페이싱)로 리듬을 만든다.

## 2. 컬러 토큰

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--ink` | `#111111` | 본문, 주요 숫자, 채움 |
| `--ink-soft` | `#555555` | 보조 텍스트 |
| `--ink-faint` | `#999999` | 캡션, 비활성 |
| `--paper` | `#FFFFFF` | 배경 |
| `--paper-dim` | `#F6F6F6` | 구획 배경 (피드백 박스 등) |
| `--line` | `#E4E4E4` | 헤어라인 경계선 |

검정/하양/회색 외의 색은 **어디에도 쓰지 않는다.** (면책 배너 포함 — 노란 배경 대신 검정 배경 + 흰 글자로 대체)

## 3. 타이포그래피

폰트: **Pretendard Variable** (한국어 최적화, CDN). 숫자는 `font-variant-numeric: tabular-nums`.

| 스타일 | 크기/행간 | 굵기 | 용도 |
|--------|----------|------|------|
| Display | 64 / 1.0 | 750 | 종합 점수 숫자 |
| Title | 26 / 1.25 | 700 | 화면 제목 |
| Heading | 17 / 1.4 | 650 | 섹션 제목 |
| Body | 15 / 1.65 | 400 | 본문 |
| Caption | 12 / 1.4 | 500 | 보조 정보 |
| Label | 11 / 1 | 600, `letter-spacing: 0.08em` | 영문 보조 라벨 (예: `OVERALL SCORE`) |

## 4. 레이아웃

- 콘텐츠 폭: **최대 520px 중앙 정렬** (모바일 앱 프로토타입이므로). 데스크톱에서는 좌우 헤어라인으로 프레임.
- 기본 여백 단위: 4px 배수. 화면 좌우 패딩 24px, 섹션 간격 40px.
- 모서리 반경: **0px** (직각). 예외 없음.
- 구획 구분: 섹션 사이 1px 헤어라인 풀블리드.

## 5. 상태(레벨) 표현 — 모노크롬 인코딩

색을 쓸 수 없으므로 다음 규칙으로 통일한다.

| 레벨 | 라벨 | 시각 표현 |
|------|------|----------|
| `good` | 양호 | 아웃라인 태그 (흰 배경 + 1px 검정 테두리) |
| `caution` | 주의 | 사선 패턴 또는 회색 채움 태그 |
| `bad` | 불균형 | **검정 채움 태그 + 흰 글자** (가장 강한 대비 = 가장 시급) |

차트/게이지: 트랙은 `--line`, 채움은 `--ink`. 점수가 낮을수록 채움이 짧아 시각적으로 자연히 드러난다.

## 6. 컴포넌트 규칙

- **버튼(주):** 검정 배경, 흰 글자, 직각, 높이 52px, 풀폭. hover 시 `#000`.
- **버튼(보조):** 흰 배경, 1px 검정 테두리.
- **텍스트 버튼:** 밑줄, `--ink-soft`.
- **골격 오버레이:** 흑백 사진 위에 흰 선(굵기 2.5px) + 검정 헤일로(굵기 5px, 투명도 35%)로 가독성 확보. 관절점은 흰 원 + 검정 테두리. 신뢰도 0.5–0.8은 빈 원, 0.5 미만은 미표시. 중앙 수직 기준선은 흰 점선(투명도 70%).
- **면책 배너:** 검정 배경 풀블리드, 흰 글자 12px, 결과 화면 최상단 고정.
- **추이 차트:** 손수 그린 SVG. 검정 꺾은선 + 검정 점, 그리드는 헤어라인. 장식 없음.

## 7. 문장 톤

- 짧고 단정하게. 느낌표·이모지 금지.
- 의료적 단정 금지: "~입니다" 대신 "~로 측정되었습니다", "참고하세요".
